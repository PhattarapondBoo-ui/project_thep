# ระบบเช็คลิสต์งานพนักงาน

เว็บสำหรับมอบหมายงานและตรวจงานพนักงาน ใช้แค่ **Python** (ไม่ต้องติดตั้งอะไรเพิ่ม)

## วิธีเปิดใช้งาน
1. ดับเบิลคลิก `start.bat` (หรือพิมพ์ `python server.py`)
2. เปิด http://localhost:8000
3. มือถือที่ต่อ WiFi เดียวกัน เปิดลิงก์ `http://<IP เครื่องนี้>:8000` ตามที่หน้าต่างดำแสดง
   (ถ้าเปิดไม่ได้ ให้อนุญาต Python ใน Windows Firewall)

## บัญชีเริ่มต้น (เปลี่ยนรหัสด้วยปุ่ม 🔑 หลังเข้าใช้ครั้งแรก)
| ประเภท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| นายจ้าง | admin | admin123 |
| พนักงาน | staff1 | 1234 |

## การใช้งาน
**นายจ้าง**
- เพิ่ม / แก้ไข / ลบงาน (ชื่องาน, โซน, มอบหมายให้ใคร หรือ "ทุกคน", วันกำหนดเสร็จ, รายละเอียด)
- ดูรูปที่พนักงานส่ง → กด **✔ Checklist Complete** หรือ **↩ ส่งกลับให้ทำใหม่** (ใส่เหตุผลได้)
- แท็บ "จัดการพนักงาน" เพิ่ม/ลบบัญชีพนักงานและนายจ้าง

**พนักงาน**
- เห็นงานที่มอบหมายให้ตัวเอง + งานของ "ทุกคน"
- ถ่ายรูป/เลือกรูป → ใส่หมายเหตุ → กด **ส่งงาน** (รูปถูกย่อขนาดอัตโนมัติ)

สถานะงาน: `ยังไม่ทำ` → `รอตรวจ` → `เสร็จแล้ว`

## โครงสร้างไฟล์ (แก้ไขตรงไหน)
| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | เซิร์ฟเวอร์ + ฐานข้อมูล + ล็อกอิน (พอร์ต, บัญชีเริ่มต้น อยู่ด้านบนไฟล์) |
| `public/app.js` | หน้าจอทั้งหมด (ข้อความสถานะอยู่บนสุดของไฟล์) |
| `public/style.css` | สีและหน้าตา (เปลี่ยนสีที่ `:root` บนสุด) |
| `data.db` | ฐานข้อมูล (สร้างอัตโนมัติ — **สำรองไฟล์นี้กับโฟลเดอร์ `uploads/`**) |
| `uploads/` | รูปที่พนักงานอัปโหลด |

ลบ `data.db` และ `uploads/` = เริ่มระบบใหม่ทั้งหมด
